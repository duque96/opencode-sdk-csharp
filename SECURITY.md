# Security Policy

## Reporting a vulnerability

If you believe you have found a security issue in this repository, report it privately by email to `security@ddb.cat`.

Please include:

- A clear description of the issue
- Affected versions or commit range, if known
- Reproduction steps or a minimal proof of concept
- Any suggested mitigations

Do not open a public GitHub issue for suspected vulnerabilities.

## Disclosure expectations

Please allow reasonable time for investigation, remediation, and coordinated disclosure before sharing details publicly.

## Scope

This policy applies to the code in this repository and its published NuGet package. Issues in Opencode services or infrastructure outside this repository should be reported to the appropriate upstream maintainers.
